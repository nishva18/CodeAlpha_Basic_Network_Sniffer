# CodeAlpha Task 1 – Basic Network Sniffer

## Project Overview
A Python program that captures and analyzes network packets using Scapy.

## Features
- Displays source and destination IP addresses
- Identifies TCP, UDP, and ICMP protocols
- Shows source and destination ports
- Displays packet length and payload information

## Technologies Used
- Python
- Scapy
- Npcap

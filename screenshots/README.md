# CodeAlpha Task 1 – Basic Network Sniffer

## Project Overview

A Python-based network sniffer that captures and analyzes network packets using Scapy.

## Features

* Captures network packets.
* Displays source and destination IP addresses.
* Identifies protocols such as TCP, UDP, and ICMP.
* Displays source and destination ports.
* Shows packet length and payload information.

## Technologies Used

* Python
* Scapy
* Npcap
